2. KIẾN TRÚC ĐÍCH
======================================================================

Java + XML + Material 3
        |
        v
Multi-Activity + ViewBinding
        |
        v
ViewModel + LiveData
        |
        v
Repository
        |
        +-- Room/SQLite
        +-- AI Service abstraction
        +-- WorkManager

Tech stack đề xuất:

- Ngôn ngữ: Java 17.
- UI: XML + Material 3.
- Navigation: Multi-Activity, không Fragment, không NavComponent.
- View access: ViewBinding.
- Local database: SQLite + Room.
- Data layer: Entity + DAO + Repository.
- UI state: ViewModel + LiveData.
- Background database work: ExecutorService.
- Offline/background jobs: WorkManager.
- Camera: CameraX.
- OCR: ML Kit Text Recognition.
- Network: OkHttp/Retrofit hoặc AiService abstraction.
- AI provider: không gắn cứng vào Activity hoặc Repository.
- JSON: Gson.
- Preferences: SharedPreferences chỉ giữ session/theme/UI state nhẹ.
- Testing: JUnit + Android Room instrumentation tests.

10. PHASE 5 - PRACTICE/QUIZ HYBRID
======================================================================

Đây là phase trọng tâm.

10.1. State machine

LOADING
  -> QUESTION_ACTIVE
  -> SAVING_ANSWER
  -> ANSWER_REVEALED
  -> NEXT_QUESTION
  -> COMPLETED

10.2. Timer

- Giữ giao diện và thời lượng timer từ main.
- ViewModel quản lý deadline và remaining time.
- Activity chỉ render timer.
- Tính remaining bằng thời gian monotonic/deadline, tránh reset khi xoay.
- Khi người dùng trả lời:
  + Dừng timer.
  + Khóa input.
  + Lưu answer vào Room.
  + Chỉ reveal sau khi lưu thành công.
- Khi hết giờ:
  + Lưu timed_out=true.
  + Đánh dấu incorrect.
  + Reveal đáp án đúng.
  + Không tự nhảy ngay trước khi người dùng đọc feedback.

10.3. Multiple choice

- Hiện option cards từ main.
- Ẩn text input.
- Chọn option sẽ khóa lựa chọn.
- Tô xanh đáp án đúng.
- Tô đỏ lựa chọn sai.
- Hiện explanation.

10.4. Short answer

- Ẩn option cards.
- Hiện TextInputEditText.
- Có nút Check Answer.
- Chuẩn hóa trước khi đánh giá.
- Hỗ trợ acceptable_answers_json.

10.5. Fill in the blank

- Hiện câu có vị trí trống.
- Hiện input phù hợp.
- Khi reveal, hiển thị câu hoàn chỉnh và explanation.

10.6. Answer evaluation

Tạo lớp QuizAnswerEvaluator độc lập:

AnswerEvaluation evaluate(
    QuizQuestionEntity question,
    String userAnswer
)

Hỗ trợ:

- Chuẩn hóa khoảng trắng.
- Hoa/thường theo cấu hình.
- Nhiều đáp án chấp nhận được.
- Numeric tolerance.
- Không để Activity tự tính điểm.

10.7. Nguồn quiz

Ưu tiên:

1. Attempt đang làm dở trong Room.
2. Quiz đã lưu trong Room.
3. Online: AI tạo quiz từ lịch sử thật.
4. Offline và chưa có quiz: hiện empty state trung thực.

quiz_questions.json chỉ được giữ làm test fixture, không dùng production.

10.8. Hoàn thành attempt

- Điểm được tính lại từ quiz_answers trong Room.
- UI không truyền điểm như nguồn sự thật.
- Attempt chỉ được complete một lần.
- XP chỉ được cộng một lần theo attempt ID.
- QuizResult đọc dữ liệu persisted.
